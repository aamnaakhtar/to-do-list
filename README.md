# 📝 React To-Do List App

A simple and functional **To-Do List application built using React.js**.  
This project was created to practice **React hooks, state management, component communication, and localStorage persistence**.

---

## 🚀 Features

- ➕ Add new to-do items  
- ✅ Mark tasks as completed using a checkbox  
- ❌ Delete tasks from the list  
- 💾 Persistent storage using **localStorage**  
- 🎯 Clean component-based structure  
- ⚛️ Built using **React functional components & hooks**

---

## 🧠 Concepts Used

- `useState` – managing to-do list state  
- `useEffect` – syncing data with localStorage  
- `useRef` – handling input field value  
- Controlled components (checkbox)  
- Props & lifting state up  
- Immutable state updates
